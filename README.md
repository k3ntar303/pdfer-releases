# PDFer

**ダウンロードはこちらのページから: https://k3ntar303.github.io/pdfer-releases/**

図面・書類のPDF(とJPG)に、手書き・寸法・矢印・文字などを書き込めるアプリです。
Windows パソコン版と Android スマホ・タブレット版(Android 12 以上)があります。

## パソコン(Windows)に入れる

1. 下のリンクを押してダウンロードします。

   **[PDFer(パソコン版)をダウンロード](https://github.com/k3ntar303/pdfer-releases/raw/main/PDFer.msi)**

2. ダウンロードした「PDFer.msi」を開きます。
3. 「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押してください。
   (お店で売っているソフトのような「発行元の証明書」を付けていないので出る表示です)
4. そのままインストールが進み、スタートメニューとデスクトップに「PDFer」ができます。
5. PDFをダブルクリックでPDFerで開くには: PDFerの設定(右上の歯車)→「PDFの標準アプリにする」を押し、開いた画面で「.pdf」を「PDFer」にします


## スマホ・タブレット(Android)に入れる

1. スマホのChromeで、下のリンクを押してダウンロードします。

   **[PDFer(スマホ版)をダウンロード](https://github.com/k3ntar303/pdfer-releases/raw/main/PDFer.apk)**

   「このファイルは有害な可能性があります」と出たら「ダウンロード」を押してください(Playストア以外のアプリには必ず出る表示です)。

2. ダウンロードが終わったら「開く」を押します。
3. 「この提供元のアプリを許可しない設定になっています」と出たら「設定」→「この提供元のアプリを許可」をONにして、戻ります。
4. 「インストール」を押します。
   - 「Google Play プロテクト」の確認が出たら「詳細」→「インストールする」を押してください。

## 更新

新しい版ができると、アプリのホームの画面の上に「新しい版があります」と出ます。「更新する」を押すと更新できます。
(パソコン版はPDFerがいったん閉じて、更新が終わると開き直します)

お知らせは1日1回確かめます。すぐ確かめたい時は、ホームの右上の歯車(設定)→「今すぐ確認」を押してください。

## 使い方

アプリのホームの画面の「?」(使い方)を見てください。
